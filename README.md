## 为什么在 GitHub 里点 `index.html` 打不开游戏？

GitHub 仓库页面只是**存文件**的地方，它会把 `.html` 当纯文本展示，不会执行里面的脚本、也不会加载 wasm，所以直接点文件是玩不了的。

真正让 GitHub 帮你「跑网站」的功能叫 **GitHub Pages**。本仓库已经开启：它把 `docs/` 文件夹当作一个网站发布，所以 [ze207920.github.io/-/](https://ze207920.github.io/-/) 就是仓库里的游戏，代码和资源都在这个仓库中，改了仓库内容、Pages 上的游戏也会跟着更新。

因此「在 GitHub 中打开游戏」的正确姿势是：

1. 打开仓库首页 <https://github.com/Ze207920/-
2. 点最上面这个 **🎮 点这里直接开始游戏** 链接（或右侧 About 栏的 Website 链接）
3. 直接收藏 Pages 网址，以后一键打开

## 游戏内容

- 四个可选角色：吴邪、张起灵、王胖子、黑瞎子，各有属性与三招技能
- 每升 5 级解锁一招，集齐三招后转为技能强化（Lv15 起每 5 级 +1 层）
- 八张主题挑战地图（七星鲁王宫、积尸地、蛇沼鬼城、西沙海底墓、云顶天宫、青铜神树、西王母宫、长白山）＋随机障碍
- 无尽模式与挑战模式并存
- 手机触屏摇杆、右下角技能按钮

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左半屏浮动摇杆 |
| 放技能 | `E` 或空格（全放）、`1` `2` `3`（单放） | 右下角技能按钮 |
| 暂停 | `Esc` / `P` | 右上角暂停按钮 |
| 选角色 | 标题页点「选择角色」或按 `Tab` | 点「选择角色」 |

## 仓库结构

| 目录 | 内容 |
| --- | --- |
| `scripts/` | 全部游戏逻辑（GDScript） |
| `art/`、`audio/`、`assets/` | 图片、音效、字体 |
| `game.tscn` / `project.godot` | 主场景与工程入口，用 Godot 4.7 打开即可改游戏 |
| `build/web/` | 网页成品（可直接部署的一套文件） |
| `docs/` | **GitHub Pages 发布目录**，内容与 `build/web` 一致 |
| `tools/` | 字体子集、网页导出、版本戳、冒烟测试等脚本 |

## 本地运行 / 更新

- 用 Godot 编辑器打开 `project.godot` 直接运行源码；或双击 `play_game.bat`
- 打开本地网页成品：双击 `play_web.bat`
- 重新导出网页版：双击 `export_web.bat`，它会自动给游戏包打内容版本戳、并把新版本同步到 `docs/`
- 同步到 GitHub 后，Pages 上的游戏会自动更新（约 1 分钟）

> 注意：`.godot/` 编辑器缓存、`tools/godot/` 便携版引擎、调试截图未入库，均可随时再生成。
